# EVENTMER · Frontend

React + **Next.js 14** (App Router, TypeScript) + **Tailwind CSS**.

Um único app atende as três experiências:

- **Público** — página do evento e inscrição (`/e/[slug]`)
- **Participante** — "Meus ingressos" (`/meus-ingressos`)
- **Organizador / Recepção** — painel (`/painel`) e check-in PWA (`/checkin/[sessionId]`)

> Scaffolding pendente — primeira entrega da Fase 0. Estrutura planejada em [`docs/04-arquitetura.md`](../docs/04-arquitetura.md#3-organização-do-código).
